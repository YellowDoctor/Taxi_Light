# 🚕 Такси Шашка — умный ночник на ESP32

Премиальный умный ночник в форме такси-шашки на базе **ESP32** и адресной ленты **WS2812B**. Управление через современный встроенный веб-интерфейс (SPA с тёмной темой, десктопной адаптацией и WebSocket в реальном времени), мобильное PWA-приложение, сенсорную кнопку и OTA-обновления по Wi-Fi.

> **Релиз v1.3.6** — полноценный PWA с минималистичной адаптивной иконкой, Service Worker, подключением по сетевому имени `taxilight.local` (mDNS/NetBIOS), десктопной адаптацией дашборда, высокоточным измерением аккумулятора через `esp_adc_cal` с кривой Li-Ion и 16 световыми эффектами.

---

## ✨ Возможности

### 💡 Освещение и эффекты
- 🎨 **16 динамических эффектов:** статика, дыхание, радуга, огонь, свеча, перелив, северное сияние, океан, полиция, мигалка, метеор, стробоскоп, гирлянда, ночное небо, лазер, вспышки.
- 🌅 **Будильник-рассвет (Sunrise Alarm):** мягкое естественное пробуждение с квадратичной кривой нарастания яркости и цветовым градиентом от глубокого рассветного красного к теплому белому.
- ⏰ **Расписание (Scheduler):** автоматическое включение и выключение по дням недели с точной синхронизацией времени через NTP.
- ⏱️ **Таймер сна (Sleep Timer):** автовыключение через 15, 30, 60 минут или произвольное время с обратным отсчётом в интерфейсе.
- ⭐ **Избранные сцены (Favorites):** сохранение до 5 любимых пресетов (цвет, эффект, яркость, скорость) в энергонезависимую память NVS.
- ⚡ **WebSocket в реальном времени:** мгновенная синхронизация состояния между ночником и всеми открытыми вкладками браузера без постоянного polling.

### 🔋 Точный мониторинг аккумулятора
- 🎯 **Заводская калибровка АЦП (`esp_adc_cal`):** считывание точных милливольт с использованием калибровочных таблиц eFuse, прошитых на заводе Espressif (компенсирует нелинейность АЦП ESP32).
- 📈 **11-точечная нелинейная таблица (LUT):** честный расчёт процента заряда по физической кривой разряда Li-Ion 21700 (3.20 В = 0% … 4.20 В = 100%).
- 🛡️ **Экспоненциальный фильтр (EMA, $\alpha = 0.15$):** устраняет скачки напряжения при переключении ярких эффектов.
- ⚡ **Умный детектор зарядки:** автоматическая индикация `⚡` при стабильном росте напряжения.
- 💎 **Встроенный виджет в кнопку питания:** компактная полупрозрачная плашка с индикатором заряда, процентом и вольтажом прямо в карточке включения.

### 📱 Мобильное PWA-приложение и Десктопный интерфейс
- 📲 **Полноценное PWA (Progressive Web App):** установка на экран смартфона через Chrome / Safari с запуском в отдельном окне без рамок и адресной строки браузера.
- ⬛ **Минималистичный дизайн ярлыка:** культовые шашечки такси на чистом фоне. Векторный SVG адаптируется под тему телефона (светлая/тёмная).
- ⚙️ **Встроенный Service Worker (`sw.js`) и PNG-иконка (192×192):** гарантируют распознавание приложения операционной системой Android (WebAPK).
- ⛶ **Полноэкранный режим в один клик:** кнопка `⛶` в шапке разворачивает интерфейс на весь экран смартфона или монитора.
- 🖥️ **Десктопная адаптация (Desktop Layout):** 
  - Главная страница: просторный 2-колоночный дашборд (слева управление питанием и статус, справа яркость, палитра, таймеры).
  - Эффекты: адаптивная сетка на 4–5 колонок вместо двух.
  - Нижняя панель навигации: плавающий элегантный dock-остров по центру экрана с горизонтальными кнопками и `:hover`-эффектами.

### 🌐 Сеть и подключение
- 🏷️ **Подключение по имени (без ввода IP):**
  - **`http://taxilight.local`** — через **mDNS** (iOS Safari, Android Chrome, macOS, Windows).
  - **`http://taxilight`** — через **NetBIOS** (Windows).
- 📶 **Асинхронный Wi-Fi с Captive Portal:** автоподключение без задержек в работе светодиодов; при отсутствии сети поднимается точка доступа `TaxiLight`.
- 🔄 **Беспроводная прошивка (OTA):** обновление через ArduinoOTA по сети или прямо из веб-интерфейса по URL.
- 🛠 **Страница разработчика `/dev`:** живая телеметрия, кольцевой лог событий, тест светодиодов и системные команды.

## 🔌 Схема подключения

| Компонент                  | Вывод ESP32 | Примечание                                    |
|----------------------------|-------------|-----------------------------------------------|
| Данные ленты WS2812B (DIN) | GPIO 5      | 34 светодиода; резистор 330–470 Ом            |
| Сенсорная кнопка (TTP223)  | GPIO 4 (T0) | Цифровой вход или сенсорный канал T0          |
| Измерение АКБ              | GPIO 34     | ADC1 вход через делитель 100 кОм / 100 кОм    |
| Питание ленты (+5V)        | 5V / buck   | Общий минус (GND) с ESP32 обязателен          |
| GND                        | GND         | Общая земля                                   |

**Питание:** два аккумулятора 21700 параллельно (3.2–4.2 В) → buck-boost преобразователь на 3.3 В / 5 В. Зарядка через USB-C (TP4056 / Type-C контроллер).

## 🚀 Прошивка (PlatformIO)

```bash
# 1. Сборка проекта
pio run

# 2. Первая прошивка по USB
pio run -t upload

# 3. Монитор серийного порта (115200 бод)
pio run -t monitor

# 4. Обновление по воздуху (OTA по IP)
pio run -t upload --upload-port 192.168.0.249

# 5. Обновление по воздуху (OTA по mDNS)
pio run -t upload --upload-port taxilight.local
```

> Пароль OTA по умолчанию: `taxilight_ota`

## 📲 Первый запуск и настройка

1. После первой прошивки устройство создаст точку доступа **`TaxiLight`** (пароль **`12345678`**).
2. Подключитесь к ней со смартфона — автоматически откроется окно быстрой настройки (или перейдите на `http://192.168.4.1`).
3. В разделе **Настройки → Wi-Fi** выберите домашнюю сеть и введите пароль.
4. После подключения ночник доступен по адресу **`http://taxilight.local`** (на Windows также **`http://taxilight`**).
5. Чтобы сбросить настройки Wi-Fi и вернуться в точку доступа, удерживайте сенсорную кнопку более 5 секунд.

## 👆 Управление сенсорной кнопкой

| Жест                     | Действие по умолчанию                              |
|--------------------------|----------------------------------------------------|
| Одно касание             | Включить / выключить                               |
| Двойное касание          | Переключить на следующий эффект                    |
| Удержание (0.4–2 с)      | Плавная регулировка яркости (сохраняется при отпускании) |
| Долгое удержание (> 5 с) | Принудительный вход в режим точки доступа (AP)     |

## 🌐 REST & WebSocket API

Все эндпоинты принимают и возвращают JSON.

### WebSocket
- **`/ws`** — подключение по WebSocket для мгновенных push-обновлений статуса ночника.

### PWA & Ресурсы
| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/manifest.json` | Web App Manifest для установки PWA |
| GET | `/sw.js` | Service Worker для автономной работы и standalone режима |
| GET | `/icon.png` | Растровая иконка PNG (192×192) для Android Chrome |
| GET | `/icon.svg` | Адаптивная векторная иконка SVG (тёмная/светлая тема) |

### Управление и состояние
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/` | Главный SPA веб-интерфейс |
| GET | `/dev` | Страница диагностики разработчика |
| GET | `/api/status` | Полное состояние устройства (питание, цвет, заряд АКБ, Wi-Fi, память, таймеры) |
| POST | `/api/power` | `{"on": true/false}` — включение/выключение |
| POST | `/api/brightness` | `{"value": 0..255}` — установка яркости |
| POST | `/api/color` | `{"r": 255, "g": 180, "b": 0}` — установка цвета |
| POST | `/api/effect` | `{"id": 0..15, "speed": 0..255}` — выбор эффекта и скорости |

### Таймер сна и Рассвет
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| POST | `/api/timer` | `{"minutes": 30}` — запуск таймера сна (`0` — отмена) |
| POST | `/api/sunrise` | `{"minutes": 20, "brightness": 200}` — запуск будильника-рассвета |
| POST | `/api/sunrise/cancel` | Отмена активного рассвета |

### Избранное (Favorites)
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/api/favorites` | Получить список всех 5 слотов сцен |
| POST | `/api/favorites/save` | `{"slot": 0..4, "name": "Уют"}` — сохранить текущую сцену |
| POST | `/api/favorites/load` | `{"slot": 0..4}` — применить сохранённую сцену |
| POST | `/api/favorites/delete` | `{"slot": 0..4}` — очистить слот |

### Расписание (Schedules)
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/api/schedules` | Получить 4 записи расписания |
| POST | `/api/schedules` | `{"slot": 0..3, "enabled": true, "hour": 22, "minute": 30, "action": false, "days": 127}` |
| POST | `/api/schedules/delete` | `{"slot": 0..3}` — удалить запись расписания |

### Сеть и система
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/api/wifi/scan` | Сканирование сетей Wi-Fi |
| POST | `/api/wifi/connect` | `{"ssid": "MyNet", "pass": "secret"}` — асинхронное подключение |
| POST | `/api/wifi/forget` | Забыть сеть и переключиться в AP |
| GET | `/api/settings` | Получить настройки системы |
| POST | `/api/settings` | Обновление настроек (имя устройства, часовой пояс, действия кнопки) |
| POST | `/api/settings/reset` | Сброс всех настроек к заводским значениям |
| POST | `/api/ota/url` | `{"url": "http://.../firmware.bin"}` — запуск OTA по ссылке |
| POST | `/api/reboot` | Безопасная асинхронная перезагрузка устройства |
| POST | `/api/test/led` | Тест ленты (радуга на 5 секунд) |
| GET | `/api/log` | Кольцевой лог системных событий |

## 📁 Структура проекта

```
taxi_light/
├── platformio.ini              Конфигурация PlatformIO и зависимости библиотек
├── README.md                   Документация проекта
└── src/
    ├── main.cpp                Точка входа, связывание модулей, неблокирующий loop
    ├── Config.h                Все глобальные константы (пины, тайминги, эффекты, версия)
    ├── modules/
    │   ├── SettingsManager.*   Хранение настроек, избранного и расписания в NVS (Preferences)
    │   ├── WiFiManager.*       Wi-Fi клиент, точка доступа, Captive Portal, NTP, mDNS, NetBIOS
    │   ├── WebServer.*         REST API, WebSocket (/ws), PWA манифест, Service Worker, UI
    │   ├── LedManager.*        Драйвер светодиодной ленты WS2812B (FastLED)
    │   ├── EffectsManager.*    16 неблокирующих динамических световых эффектов
    │   ├── SunriseManager.*    Будильник-рассвет с кривой яркости и цветовым градиентом
    │   ├── ScheduleManager.*   Менеджер расписания по дням недели на базе NTP
    │   ├── BatteryManager.*    esp_adc_cal калибровка АЦП, LUT разряда Li-Ion, EMA-фильтр
    │   ├── ButtonManager.*     Сенсорная кнопка, фильтрация дребезга и жесты
    │   └── OtaManager.*        Беспроводное обновление прошивки (ArduinoOTA / HTTP)
    └── web/
        ├── ui.h                Встроенный SPA веб-интерфейс, SVG иконка, dev-страница
        └── icon_png.inl        Встроенный растровый байткод PNG-иконки для PWA
```

## ⚙️ Основные константы (`src/Config.h`)

| Константа | Значение | Описание |
|-----------|:--------:|----------|
| `FIRMWARE_VERSION` | `"1.3.6"` | Текущая версия прошивки |
| `LED_PIN` | `5` | Пин данных ленты WS2812B (GPIO5) |
| `LED_COUNT` | `34` | Количество светодиодов в корпусе |
| `BUTTON_PIN` / `TOUCH_PIN` | `4` / `T0` | Пин сенсорной кнопки (GPIO4) |
| `BATTERY_PIN` | `34` | Аналоговый пин измерения АКБ |
| `BATTERY_MIN_VOLTAGE` | `3.2f` | 0% (безопасный минимум Li-Ion) |
| `BATTERY_MAX_VOLTAGE` | `4.2f` | 100% (полный заряд Li-Ion) |
| `BATTERY_DIVIDER_RATIO` | `2.0` | Делитель напряжения резисторов 100к / 100к |
| `AP_SSID` / `AP_PASSWORD` | `TaxiLight` / `12345678` | Параметры точки доступа по умолчанию |
| `WIFI_MAX_RETRIES` | `3` | Количество попыток подключения до fallback в AP |
| `EFFECT_COUNT` | `16` | Количество доступных эффектов |
| `FAVORITES_COUNT` | `5` | Количество слотов избранного |
| `SCHEDULE_COUNT` | `4` | Количество записей расписания |
