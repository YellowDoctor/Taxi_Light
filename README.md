# 🚕 Такси Шашка — умный ночник на ESP32

Премиальный умный ночник в форме такси-шашки на базе **ESP32** и адресной ленты **WS2812B**. Управление через современный встроенный веб-интерфейс (SPA с тёмной темой и WebSocket в реальном времени), сенсорную кнопку и OTA-обновления.

> **Версия 1.2.0** — полнофункциональная прошивка: 16 динамических эффектов, будильник-рассвет, расписание с NTP, таймер сна, избранные сцены, WebSocket-синхронизация, неблокирующий loop и OTA по Wi-Fi.

---

## ✨ Возможности

- 🎨 **16 световых эффектов:** статика, дыхание, радуга, огонь, свеча, перелив, северное сияние, океан, полиция, мигалка, метеор, стробоскоп, гирлянда, ночное небо, лазер, вспышки.
- 🌅 **Будильник-рассвет (Sunrise Alarm):** мягкое пробуждение с плавной кривой яркости и цветовым градиентом от глубокого красного к тёплому белому.
- ⏰ **Расписание (Scheduler):** автоматическое включение и выключение в заданное время по дням недели с точной синхронизацией времени через NTP.
- ⏱️ **Таймер сна (Sleep Timer):** автовыключение через 15, 30, 60 минут или произвольное время с обратным отсчётом в интерфейсе.
- ⭐ **Избранные сцены (Favorites):** сохранение до 5 любимых пресетов (цвет, эффект, яркость, скорость) в энергонезависимую память NVS.
- ⚡ **WebSocket в реальном времени:** мгновенная синхронизация состояния между ночником и всеми открытыми вкладками браузера без постоянного polling.
- 💡 **Плавное управление светом:** палитра цветов, быстрые пресеты, регулировка яркости и скорости эффектов. Предпросмотр эффекта по долгому тапу (500 мс).
- 🔋 **Мониторинг аккумулятора:** измерение напряжения и процента заряда двух элементов 21700, индикация зарядки.
- 👆 **Сенсорная кнопка (TTP223 / Touch T0):** короткое касание, двойное касание, удержание с сохранением яркости при отпускании, долгое удержание (> 5 сек) для сопряжения.
- 📶 **Надёжный Wi-Fi:** асинхронное подключение без блокировки loop, автоматический fallback в точку доступа с Captive Portal после 3 неудачных попыток.
- 🔄 **Беспроводная прошивка (OTA):** обновление через ArduinoOTA по сети или прямо из веб-интерфейса по URL.
- 🛠 **Страница разработчика `/dev`:** живая телеметрия, кольцевой лог событий, тест светодиодов и системные команды.

## 🔌 Схема подключения

| Компонент                  | Вывод ESP32 | Примечание                                    |
|----------------------------|-------------|-----------------------------------------------|
| Данные ленты WS2812B (DIN) | GPIO 5      | 34 светодиода; резистор 330–470 Ом            |
| Сенсорная кнопка (TTP223)  | GPIO 4 (T0) | Цифровой вход или сенсорный канал T0          |
| Измерение АКБ              | GPIO 34     | ADC1 вход через делитель 100 кОм / 100 кОм    |
| Питание ленты (+5V)        | 5V / buck   | Общий минус (GND) с ESP32 обязателен          |
| GND                        | GND         | Общая земля                                   |

**Питание:** два аккумулятора 21700 параллельно (3.0–4.2 В) → buck-boost преобразователь на 3.3 В / 5 В. Зарядка через USB-C (TP4056 / Type-C контроллер).

Делитель для измерения АКБ: `АКБ+ → 100 кОм → [GPIO34] → 100 кОм → GND` (коэффициент деления `BATTERY_DIVIDER_RATIO = 2.0`).

## 🚀 Прошивка (PlatformIO)

```bash
# 1. Сборка проекта
pio run

# 2. Прошивка по USB (первая прошивка)
pio run -t upload

# 3. Монитор серийного порта (115200 бод)
pio device monitor

# 4. Обновление по воздуху (OTA)
pio run -t upload --upload-port 192.168.0.249
# или по mDNS:
pio run -t upload --upload-port taxilight.local
```

> Пароль OTA по умолчанию: `taxilight_ota`

## 📲 Первый запуск и настройка

1. После первой прошивки устройство создаст точку доступа **`TaxiLight`** (пароль **`12345678`**).
2. Подключитесь к ней со смартфона — автоматически откроется Captive Portal (или перейдите на `http://192.168.4.1`).
3. В разделе **Настройки → Wi-Fi** нажмите *«Сменить сеть / сканировать»*, выберите вашу домашнюю сеть и введите пароль.
4. После подключения ночник получит IP в вашей сети и будет доступен по нему или по адресу `http://taxilight.local`.
5. Чтобы в любой момент сбросить Wi-Fi и вернуться в режим точки доступа, удерживайте сенсорную кнопку более 5 секунд.

## 👆 Управление сенсорной кнопкой

| Жест                     | Действие по умолчанию                              |
|--------------------------|----------------------------------------------------|
| Одно касание             | Включить / выключить                               |
| Двойное касание          | Переключить на следующий эффект                    |
| Удержание (0.4–2 с)      | Плавная регулировка яркости (сохраняется при отпускании) |
| Долгое удержание (> 5 с) | Принудительный вход в режим точки доступа (AP)     |

## 🌐 REST & WebSocket API

Все эндпоинты принимают и возвращают JSON.

### WebSocket
- **`/ws`** — подключение по WebSocket для получения мгновенных push-обновлений статуса ночника при любом событии.

### Управление и состояние
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/` | Главный SPA веб-интерфейс |
| GET | `/dev` | Страница диагностики разработчика |
| GET | `/api/status` | Полное состояние устройства (питание, цвет, заряд АКБ, Wi-Fi, память, таймеры) |
| POST | `/api/power` | `{"on": true/false}` — включение/выключение |
| POST | `/api/brightness` | `{"value": 0..255}` — установка яркости |
| POST | `/api/color` | `{"r": 255, "g": 180, "b": 0}` — установка цвета |
| POST | `/api/effect` | `{"id": 0..15, "speed": 0..255}` — выбор эффекта и скорости |

### Таймер сна и Рассвет
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| POST | `/api/timer` | `{"minutes": 30}` — запуск таймера сна (`0` — отмена) |
| POST | `/api/sunrise` | `{"minutes": 20, "brightness": 200}` — запуск будильника-рассвета |
| POST | `/api/sunrise/cancel` | Отмена активного рассвета |

### Избранное (Favorites)
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/api/favorites` | Получить список всех 5 слотов сцен |
| POST | `/api/favorites/save` | `{"slot": 0..4, "name": "Уют"}` — сохранить текущую сцену |
| POST | `/api/favorites/load` | `{"slot": 0..4}` — применить сохранённую сцену |
| POST | `/api/favorites/delete` | `{"slot": 0..4}` — очистить слот |

### Расписание (Schedules)
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/api/schedules` | Получить 4 записи расписания |
| POST | `/api/schedules` | `{"slot": 0..3, "enabled": true, "hour": 22, "minute": 30, "action": false, "days": 127}` |
| POST | `/api/schedules/delete` | `{"slot": 0..3}` — удалить запись расписания |

### Сеть и система
| Метод | Путь | Тело запроса / Описание |
|-------|------|-------------------------|
| GET | `/api/wifi/scan` | Сканирование сетей Wi-Fi |
| POST | `/api/wifi/connect` | `{"ssid": "MyNet", "pass": "secret"}` — асинхронное подключение |
| POST | `/api/wifi/forget` | Забыть сеть и переключиться в AP |
| GET | `/api/settings` | Получить настройки системы |
| POST | `/api/settings` | Обновление настроек (имя устройства, часовой пояс, действия кнопки) |
| POST | `/api/settings/reset` | Сброс всех настроек к заводским значениям |
| POST | `/api/ota/url` | `{"url": "http://.../firmware.bin"}` — запуск OTA по ссылке |
| POST | `/api/reboot` | Безопасная асинхронная перезагрузка устройства |
| POST | `/api/test/led` | Тест ленты (радуга на 5 секунд) |
| GET | `/api/log` | Кольцевой лог системных событий |

## 📁 Структура проекта

```
taxi_light/
├── platformio.ini              Конфигурация PlatformIO и зависимости библиотек
├── README.md                   Документация проекта
└── src/
    ├── main.cpp                Точка входа, связывание модулей, неблокирующий loop
    ├── Config.h                Все глобальные константы (пины, тайминги, эффекты)
    ├── modules/
    │   ├── SettingsManager.*   Хранение настроек, избранного и расписания в NVS (Preferences)
    │   ├── WiFiManager.*       Wi-Fi клиент, точка доступа, Captive Portal, NTP
    │   ├── WebServer.*         REST API, WebSocket (/ws), отдача веб-приложения
    │   ├── LedManager.*        Драйвер светодиодной ленты WS2812B (FastLED)
    │   ├── EffectsManager.*    16 неблокирующих динамических световых эффектов
    │   ├── SunriseManager.*    Будильник-рассвет с кривой яркости и цветовым градиентом
    │   ├── ScheduleManager.*   Менеджер расписания по дням недели на базе NTP
    │   ├── BatteryManager.*    АЦП-мониторинг напряжения и уровня заряда АКБ
    │   ├── ButtonManager.*     Сенсорная кнопка, фильтрация дребезга и жесты
    │   └── OtaManager.*        Беспроводное обновление прошивки (ArduinoOTA / HTTP)
    └── web/
        └── ui.h                Встроенный SPA веб-интерфейс и страница /dev (PROGMEM)
```

## ⚙️ Основные константы (`src/Config.h`)

| Константа | Значение | Описание |
|-----------|:--------:|----------|
| `FIRMWARE_VERSION` | `"1.2.0"` | Текущая версия прошивки |
| `LED_PIN` | `5` | Пин данных ленты WS2812B (GPIO5) |
| `LED_COUNT` | `34` | Количество светодиодов в корпусе |

| `EFFECT_COUNT` | `16` | Количество доступных эффектов |
| `FAVORITES_COUNT` | `5` | Количество слотов избранного |
| `SCHEDULE_COUNT` | `4` | Количество записей расписания |
