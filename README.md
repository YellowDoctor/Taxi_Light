# 🚕 Такси Шашка — умный ночник на ESP32

Премиальный умный ночник в форме такси-шашки на базе **ESP32** и адресной ленты
**WS2812B**. Управление через красивый встроенный веб-интерфейс (тёмная тема,
мобильный дизайн), сенсорную кнопку и OTA-обновления.

> Это **итерация 1** — рабочая база: управление светом, эффекты, Wi-Fi,
> измерение заряда, сенсорная кнопка, OTA и веб-интерфейс.

---

## ✨ Возможности

- 🎨 6 световых эффектов: статика, дыхание, радуга, огонь, свеча, перелив
- 💡 Плавная регулировка яркости и выбор цвета
- 📱 Встроенный веб-интерфейс (SPA), не требует интернета
- 🔋 Мониторинг заряда аккумулятора (напряжение + проценты)
- 👆 Сенсорная кнопка: касание / двойное касание / удержание / долгое удержание
- 📶 Wi-Fi с автоматическим fallback в режим точки доступа + captive portal
- 🔄 OTA-обновление (ArduinoOTA и по URL)
- 🛠 Страница разработчика `/dev` с диагностикой в реальном времени

## 🔌 Схема подключения

| Компонент                  | Вывод ESP32 | Примечание                                  |
|----------------------------|-------------|---------------------------------------------|
| Данные ленты WS2812B (DIN) | GPIO 0      | 34 светодиода; желательно резистор 330–470 Ом |
| Сенсорная кнопка           | GPIO 4 (T0) | Touch-канал T0                              |
| Измерение АКБ              | GPIO 34     | ADC-вход через делитель 100к/100к           |
| Питание ленты (+5V)        | 5V / buck   | Общий минус (GND) с ESP32 обязателен        |
| GND                        | GND         | Общая земля                                 |

**Питание:** два аккумулятора 21700 параллельно (3.0–4.2 В) → buck-boost 3.3 В
для ESP32. Зарядка через USB-C (TP4056).

Делитель для измерения АКБ: `АКБ+ → 100кОм → [GPIO34] → 100кОм → GND`
(коэффициент деления `BATTERY_DIVIDER_RATIO = 2.0`).

## 🚀 Прошивка (PlatformIO)

```bash
# Сборка
pio run

# Прошить по USB
pio run -t upload

# Монитор порта (115200)
pio device monitor

# OTA-загрузка (после первой USB-прошивки, устройство в сети)
pio run -t upload --upload-port taxilight.local
```

Пароль OTA: `taxilight_ota`.

---

## 📲 Первый запуск

1. После прошивки устройство создаёт точку доступа **`TaxiLight`**
   (пароль **`12345678`**).
2. Подключитесь к ней телефоном — откроется captive portal (или зайдите на
   `http://192.168.4.1`).
3. Перейдите в **Настройки → Wi-Fi**, отсканируйте сети и подключитесь к
   домашней сети.
4. После подключения устройство доступно по своему IP (виден в приложении и на
   `/dev`) или по `http://taxilight.local`.

Долгое удержание сенсорной кнопки (> 5 сек) в любой момент вернёт устройство в
режим точки доступа для повторного сопряжения.

## 👆 Управление кнопкой

| Жест                       | Действие по умолчанию          |
|----------------------------|--------------------------------|
| Одно касание               | Включить / выключить           |
| Двойное касание            | Следующий эффект               |
| Удержание (0.4–2 с)        | Плавная регулировка яркости    |
| Долгое удержание (> 5 с)   | Режим сопряжения (точка доступа) |

## 🌐 API

Все эндпоинты принимают/отдают JSON.

| Метод | Путь                   | Описание                                   |
|-------|------------------------|--------------------------------------------|
| GET   | `/`                    | Веб-приложение (SPA)                        |
| GET   | `/dev`                 | Страница разработчика                       |
| GET   | `/api/status`          | Полное состояние устройства                 |
| POST  | `/api/power`           | `{on:bool}` — питание                       |
| POST  | `/api/brightness`      | `{value:0-255}` — яркость                   |
| POST  | `/api/color`           | `{r,g,b}` — цвет                            |
| POST  | `/api/effect`          | `{id:0-5, speed:0-255}` — эффект            |
| GET   | `/api/wifi/scan`       | Список доступных сетей                       |
| POST  | `/api/wifi/connect`    | `{ssid, pass}` — подключение                |
| POST  | `/api/wifi/forget`     | Забыть сеть, вернуться в AP                  |
| GET   | `/api/settings`        | Все настройки                               |
| POST  | `/api/settings`        | Частичное обновление настроек               |
| POST  | `/api/settings/reset`  | Сброс к заводским                           |
| POST  | `/api/ota/url`         | `{url}` — OTA по URL                        |
| POST  | `/api/reboot`          | Перезагрузка                                |
| POST  | `/api/test/led`        | Тест ленты (радуга)                         |
| GET   | `/api/log`             | Лог событий (для `/dev`)                    |

## 📁 Структура проекта

```
taxi_light/
├── platformio.ini              Конфигурация PlatformIO и зависимости
├── README.md
└── src/
    ├── main.cpp                Точка входа, связывание модулей
    ├── Config.h                Все константы (пины, кол-во LED, версия)
    ├── modules/
    │   ├── SettingsManager.*   Хранение настроек в NVS (Preferences)
    │   ├── WiFiManager.*       Wi-Fi, точка доступа, captive portal
    │   ├── WebServer.*         REST API + отдача UI
    │   ├── LedManager.*        Управление лентой (FastLED)
    │   ├── EffectsManager.*    Световые эффекты (неблокирующие)
    │   ├── BatteryManager.*    Измерение заряда аккумулятора
    │   ├── ButtonManager.*     Сенсорная кнопка и жесты
    │   └── OtaManager.*        OTA-обновления
    └── web/
        └── ui.h                Встроенный веб-интерфейс (PROGMEM)
```
